# Part 5 트레이너

토익 Part 5 반복 풀이 웹앱 (갤럭시 탭 등 태블릿용, 오프라인 지원 PWA). AI API 없이 동작한다.

- **한 번 푼 문제는 다시 나오지 않는다** — 약점 테스트도 틀린 문제 반복이 아니라 약한 유형의 *새 문제*로 출제
- 종합 테스트: 묶음별 비율(어휘 10 · 품사 7 · 동사 3 · 접속사/관계사 3 · 준동사 2 · 대명사 2 · 전치사 2 · 비교/수량 1)로 30문제,
  묶음 안에서는 세부 유형의 출제 빈도 가중치(`taxonomy.json`의 `w`)에 비례해 선택
- 약점 테스트: 유형별 정답률(최근 풀이 가중)이 낮을수록 많이 출제, 한 유형 최대 6문제
- 유형 골라 풀기, 유형별 통계, 오답 노트(복습용 보기), 오류 신고
- 채점 후 30문제 전체에 해석 · **문장 형식 · 태 · 시제(각각 '왜?' 설명 포함)** · 빈칸 자리 · 문장 구조 · 해설(오답 이유) · 팁 · 어휘
  - 부사절·관계절 시제가 풀이에 중요하면 따로 표시, 시제 문제는 시제를 고른 단서(since, by the time 등) 표시
- **풀이 공식 189개**: 문제마다 적용되는 공식(예: "be동사·2형식 동사 뒤 보어 → 형용사")을 해설에 표시,
  공식 모음 화면, 통계의 '많이 틀린 공식'
- **내 단어장**: 해설 어휘·어휘 문제 보기(뜻 포함)·짝꿍 표현의 ☆로 추가, 틀린 어휘 문제는 자동 수집(설정에서 끄기 가능),
  뜻 가리기, 외움 표시, **Anki 가져오기용 파일 저장**(새 단어만), **인쇄용 보기**(오른쪽 필기 여백 → PDF 저장 후 삼성노트에서 필기)
- **날짜별 오답노트 PDF**: 그날 틀린 문제마다 보기(뜻)·정답 문장·빈칸 자리·해설·풀이 공식·**같은 공식 예문 3개 + 내가 풀었던 같은 공식 문제 1개**·외울 단어,
  끝에 '오늘 꼭 외울 것'(공식·단어 모음). 파일 이름이 `Part5 오답노트 YYYY-MM-DD`로 정해진다
  - 예문은 문제 은행과 겹치지 않게 따로 썼고(build.py가 검사), 아직 안 푼 문제는 예문으로 쓰지 않는다
- 보기 순서는 매번 섞이고, 해설 화면은 시험 때 본 순서 그대로 보여준다
- 학습 기록은 기기 브라우저에만 저장 → 설정 화면에서 백업/복원

## 구조

```
data/
  taxonomy.json          # 유형 분류(8개 묶음, 32개 세부 유형)와 종합 테스트 비율(quota)
  rules.json             # 풀이 공식 (영역·공식·설명·예시·예문 x)
  questions/<유형>.json  # 문제 은행 (유형별 파일)
scripts/build.py         # 검증 + docs/questions.json 생성
docs/                    # GitHub Pages로 배포되는 앱
  js/engine.js           # 출제·채점·약점 분석 (순수 함수)
  js/app.js              # 화면
  js/words.js            # 단어장·Anki 내보내기·공식 통계 (순수 함수)
  js/storage.js          # localStorage, 백업
  sw.js                  # 오프라인 캐시 (네트워크 우선)
tests/*.test.mjs         # node --test tests/engine.test.mjs tests/words.test.mjs
```

## 문장 형식 · 태 · 시제 데이터

문제마다 `fm`(형식), `sl`(빈칸 자리), `tn`(주절 시제 + 부사절·관계절·단서 메모), `why`(형식·태·시제의 이유)가 있다.

```bash
python3 scripts/draft_forms.py <유형>       # 형식·시제 초안 출력 (검토용)
python3 scripts/apply_forms.py <검토폴더>   # 검토 결과(fm/sl/tn) 반영
python3 scripts/explain.py                  # why 생성 (fm/tn/st 기반)
```

## 풀이 공식 · 어휘 데이터

문제마다 `r`(풀이 공식 ID, 표시 순서대로), 어휘 문제는 `k`(짝꿍 표현)와 `cm`(보기 4개의 뜻, 전치사 유형은 없음)이 있다.

```bash
python3 scripts/apply_rules.py <검토폴더>   # 공식 정의 + 문제 연결 + 어휘 데이터 반영 (형식은 스크립트 설명 참고)
```

## 문제 추가

`data/questions/<유형코드>.json`에 추가하고 빌드한다.

```json
{"q": "... ------- ...", "c": ["보기1","보기2","보기3","보기4"], "a": 0,
 "tr": "해석", "st": "[주어] ... / [동사] ...", "ex": "해설", "tip": "팁", "v": [["단어","뜻"]],
 "fm": "3형식 (...)", "sl": "빈칸 자리", "tn": ["주절: 현재완료 (...)", "부사절 ...: ..."]}
```
새 문제는 `fm`/`sl`/`tn`을 채운 뒤 `scripts/explain.py`로 `why`를 만들고, `r`(어휘 문제는 `k`·`cm`도)을 붙인다.

```bash
python3 scripts/build.py            # 검증(빈칸 1개, 보기 4개 중복 없음, 유사 문제 검사) 후 docs/questions.json 생성
node --test tests/engine.test.mjs   # 출제 로직 테스트
python3 -m http.server 8765 --directory docs   # 로컬 실행
```

- 문제 ID는 문장 해시로 자동 부여 → 파일 안 순서를 바꿔도 학습 기록 유지. 문장을 고치면 새 문제가 된다.
- 기존 문제와 85% 이상 비슷한 문장은 빌드가 거부한다 (재출제 방지).

## 출제 비중 근거

공식 통계는 없으므로 아래 공개 자료를 근거로 비중을 정했다 (2026-09 기준).

- 기출 변형 500문항 유형 분류: 품사(형용사·부사·명사) 비중이 가장 크고, 동사 중에서는 태 > 시제 ≫ 수일치
- 2016 개정 이후 경향: 단순 문법·전치사 문제 감소, 용법·뉘앙스·콜로케이션 문제 증가
- 빈출 어휘 목록(acknowledge, eligible, overdue, timely, impose, substitute, appraisal 등)을 어휘 문제에 반영

## 문제 출처

모든 문제는 이 프로젝트를 위해 새로 작성한 연습 문제다. ETS 기출·시판 교재 문제는 포함하지 않는다.
공식 문제가 아니므로 해설에 오류가 있을 수 있다 → 앱의 '오류 신고'로 표시 후 설정 화면에서 목록 복사.
